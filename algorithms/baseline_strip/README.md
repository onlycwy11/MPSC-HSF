# Strip-based baseline（忠实复现版）

对应论文：**Dingyuan Shi, Nan Zhou, Yongxin Tong, Zimu Zhou, Yi Xu, Ke Xu**, *Collision-Aware Route Planning in Warehouses Made Efficient: A Strip-based Framework*, IEEE ICDE 2023（[PDF](https://zhouzimu.github.io/paper/icde23-shi.pdf) · [DOI](https://doi.org/10.1109/ICDE55515.2023.00072)）。作者无官方 artifact，本项目按论文机制自行实现。

## 同层机制（忠实原文）

论文的核心机制全部按原文实现：

1. **GridLayer（Algorithm 1，aisle 行聚合）**：从 building map 自动检测规则网格层（等间距、完整矩形、4-邻接无缺口），每行 y 聚合为一条 latitudinal aisle strip。坐标用物理米，格距从地图自动推导（L-8F 为 2.5 m），电梯/楼梯井道若不在网格上自动吸附到最近格点。
2. **1-D 时空线段（Segment）**：`Segment(strip, x0, t0, x1, t1)`，斜率为 ±v 或 0，`pos(t)` 求时刻位置。
3. **几何相交判定（论文 Eq.2/3 连续化）**：两条段在时间重叠窗内位置差变号即相交；时间采用开区间语义（端点接触不算冲突，先到先得、到达即释放）。
4. **斜率索引（Algorithm 3）**：按斜率分 pos/neg/zero 三桶；同斜率段用旋转坐标（Eq.4，+v 转 -π/4、-v 转 +π/4、水平用 x 轴）做空间过滤后再判定；异斜率段按时间重叠过滤。
5. **等待法（Algorithm 2 的连续化，用户批准的简化）**：先试直达段，与已规划段冲突就把整段出发时间顺延到"冲突段结束 + MIN_STEP"（FIFO：后规划者让先规划者），收敛后插入索引。

## 跨层适配（用户确认的简化，可写入论文）

论文只覆盖单层仓库；本项目按用户确认的简化方案处理垂直移动：

- **跨层 = 图间转移**：机器人先在当前层 strip 内走到最优电梯/楼梯 landing，然后**一次乘梯直达**目标层（电梯 `4.5 + 1.75·|Δfloor|` 秒，楼梯 `3.5·|Δfloor| / 0.5` 秒），再在新层 strip 内继续。这与"从一个图转移到另一个图、转移时间即通行时间"的方案一致。
- **垂直资源预约表**：电梯/楼梯为容量 1 资源，共享 FIFO 预约表（`elevator_free`），跨 batch 持续传递。
- **分配**：匈牙利初分配，成本 = 层内 strip 最短路 + 一次乘梯；类型（task_type）必须匹配。

## 已验证行为

- 单层对向让行：后规划者等待先规划者通过后再出发（B 等 A）。
- 真实 case `A_R1_M1_F8_S17.json`（L-8F 地图，8 层 40×40 格距 2.5 m）：单任务完成时间 **301.0 s**，与忠实 CBS / TP 输出一致。
- 双机器人同起点同任务：第二台全程 FIFO 跟随（总等待 41.7 s）。
- virtual 6 台默认配置：0.4 s 内完成，无冲突。

## 与论文的差异说明（写进论文时可引用的简化理由）

- 论文假设单层规则仓库；跨层转移为本项目场景扩展，采用最简单的"一次乘梯 + FIFO"。
- 论文等待策略为逐段试探的迭代式；本项目采用"整体延迟出发"的连续化（用户批准），保证收敛且有界。
- 单位速度假设改为物理模型（平面 1.5 m/s、楼梯 0.5 m/s、层高 3.5 m、电梯 4.5+1.75/层），所有参数可配置。
